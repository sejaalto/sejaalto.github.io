2. O que preciso saber pra começar na área de dados?

O que estudar. Sem enrolação.

Resumo: SQL e Inglês. Nessa ordem.
Há outras ferramentas bem importantes pra se aprender também, mas aí vai depender de qual área de dados você quer seguir - mas SQL e inglês são fundamentais pra qualquer uma das três áreas. Além dessas duas skills, aqui vão outras importantes pra chegar em entrevistas sabendo:
- Análise de dados: saber fazer dashboards, Excel básico, estatística básica e storytelling.
- Ciência de dados: conceitos de machine learning e Python.
- Engenharia de dados: Python, Spark e Airflow.

Bora falar de SQL, inglês e depois de cada uma das 3 áreas de dados em detalhes.

SQL

SQL é a ferramenta utilizada pra puxar os dados de bancos de dados. Ou seja: sem SQL não tem como trabalhar (vai fazer o quê sem os dados?). Você vai utilizar SQL praticamente todo dia. Inclusive, conheço times que utilizam SQL diariamente mesmo não sendo de dados. São times bem interessantes, inclusive.
Good news: é uma linguagem super fácil de aprender. Há muitos recursos gratuitos e bons na internet.

Aqui minha recomendação de como aprender SQL rápido: HackerRank e ChatGPT
HackerRank é uma plataforma que você aprender a programar resolvendo desafios. É gamificado, então você pode compartilhar sua pontuação do HackerRank no seu currículo e LinkedIn, e é de graça. Bem legal! Aprendi bastante com o HackerRank. E eu usaria o ChatGPT pra ajudar no processo.

Inglês

Tema complexo. Acho muito difícil chegar longe se não for em inglês. É possível entrar no mercado sem saber, mas você vai fechar muitas portas. Muitas. Conheço empresas com operação 100% nacional que exigem inglês. Acredito que se você for seguindo sua carreira sem inglês, em algum momento você vai encontrar um teto.
Infelizmente, eu acho que não é tão simples aprender esse idioma como é aprender SQL. Mas dá. E tem muita coisa boa e gratuita na internet pra te ajudar.

Análise de dados

Acho que, dos 3 campos, a análise de dados é a que mais se comunica com os times de business. Por isso, é importante saber se comunicar bem: dashboards que resolvem problemas, planilhas claras, slides com insights, etc.
Aqui, eu acho que experiência conta muito - é difícil adquirir esse conhecimento de negócio e comunicação com cursos. Por isso acho importante que você se exponha bastante a projetos de análise de dados, pra poder adquirir essas habilidades. Pra não falar que não recomendei nada: gosto muito do livro Storytelling with Data, da Cole Nussbaumer Knaflic. Recomendação canônica quando o assunto é fazer visualizações que trazem bons insights.

Ciência de dados

Uma área bem mais técnica que a análise de dados - por isso vai ter muito mais curso bom disponível por aí pra aprender sobre. E também muitas IAs já sabem te dar uma base excelente pra esse campo.
Pra ciência de dados, você precisa aprender a construir modelos preditivos. Pra isso, você precisa de uma base conceitual boa de Machine Learning e saber materializar isso usando Python. O curso Machine Learning, do Andrew Ng é um clássico pra aprender os conceitos de ML - ele é mais teórico, mas é uma base muito boa -, e o livro Hands-on Machine Learning, do Aurélien Géron, bem mais prático. Esses 2 juntos formam uma boa dupla pra começar na área.

Engenharia de dados

A engenharia de dados é a área mais técnica das 3, e é a que tem menos conteúdo gratuito de qualidade disponível. Mas, felizmente, as IAs já sabem te dar uma base excelente pra aprender sobre isso também.
Pra engenharia de dados, você precisa aprender a construir pipelines de dados. Pra isso, você precisa saber programar em Python e conhecer ferramentas como Spark e Airflow. São ferramentas que não são simples de se trabalhar, então vale a pena procurar recursos bons pra aprender sobre elas. Eu não tenho muito domínio sobre, mas com certeza tem muita gente boa falando sobre isso na internet - só caçar.
